# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-03-27

### Added

- Monorepo consolidation of all Sprite Foundry asset packs
- Shared verification tooling (`tooling/verify-all.mjs`)
- pnpm workspace configuration for independent pack publishing

### Packs included

- `@sprite-foundry/undead-patrol-48` v1.0.0 — 8 zombie variants
- `@sprite-foundry/goblin-warband-48` v1.0.1 — 8 goblin variants
- `@sprite-foundry/fantasy-heroes-48` v1.0.1 — 8 hero archetypes
- `@sprite-foundry/fantasy-villains-48` v1.0.1 — 8 villain archetypes
- `@sprite-foundry/pirate-raiders-48` v1.0.0 — 8 pirate archetypes
