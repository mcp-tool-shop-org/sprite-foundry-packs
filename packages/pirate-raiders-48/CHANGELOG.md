# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-03-27

### Added

- **8 pirate archetypes** — Captain, Quartermaster, Cutthroat Boarder, Pistol Duelist, Navy Sailor, Harbor Governor, Drowned Guardian, Sea Priest
- **192 sprite assets** — 8 variants × 8 directions × 3 layers (albedo, normal, depth)
- **48×48 transparent PNG** — pixel-art sprites with center_bottom pivot
- **Export Contract v1.0.0** — frozen schema with SHA-256 checksums per asset
- **pack.json** — machine-readable pack manifest with variant metadata
- **Contact sheet previews** — visual reference for each variant
- **npm verify script** — validates all 192 assets against pack.json
